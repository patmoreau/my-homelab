# Ansible

## Setup

Ansible connects to all LXC hosts as `root` using the `~/.ssh/terraform_homelab` key (generated by Terraform).

Key config files:

| File                              | Purpose                                                  | Git        |
| --------------------------------- | -------------------------------------------------------- | ---------- |
| `ansible.cfg`                     | Sets inventory, vault password file, SSH options         | Committed  |
| `inventory/hosts.yaml`            | LXC and Hypervisor host IPs                              | Committed  |
| `group_vars/all/main.yaml`        | Shared variables (user, paths, domains, node name, etc.) | Committed  |
| `group_vars/all/vault.yaml`       | Plaintext secrets — Ansible reads this                   | Gitignored |
| `group_vars/all/vault.yaml.vault` | Encrypted copy of vault.yaml                             | Committed  |
| `.vault_pass`                     | Vault password file (one line, plain text)               | Gitignored |
| `vault.sh`                        | Helper script to edit/encrypt/decrypt vault              | Committed  |
| `requirements.yml`                | Ansible Galaxy collection dependencies                   | Committed  |

## First-time setup

Install required Ansible Galaxy collections (run once on your local machine from the `ansible/` directory):

```bash
cd ansible
ansible-galaxy collection install -r requirements.yml
```

## Vault workflow

```bash
./vault.sh edit      # decrypt + open editor + re-encrypt in one step
./vault.sh encrypt   # after manually editing vault.yaml, save encrypted copy
./vault.sh decrypt   # on a new machine, restore plaintext from vault.yaml.vault
```

On a new machine, restore the vault with:

```bash
echo "YOUR_VAULT_PASSWORD" > ansible/.vault_pass
chmod 600 ansible/.vault_pass
cd ansible && ./vault.sh decrypt
```

## Deploy playbook

### Ping all hosts

```bash
ansible all -i inventory/hosts.yaml -m ping
```

### Deploy all

```bash
cd ansible
ansible-playbook -i inventory/hosts.yaml site.yaml
```

### Deploy single host

```bash
cd ansible
ansible-playbook -i inventory/hosts.yaml site.yaml --limit lxc-media
```
